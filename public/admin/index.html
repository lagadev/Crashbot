Bonuses, TON wallet, and crash-behaviour tuning

Bonuses

First Deposit Bonus is extra stars credited to a user themselves the first time they deposit (e.g. 10% means depositing 100 gives 110). This is separate from the referrer's rewards below.

Referral Rewards

Both shown live in the Mini App's Refer tab.

TON / GRAM Deposits

Deposits are verified via the TonCenter API by matching a uniquely-generated payment amount - see the README for details and its limitations before relying on this for real funds.

TK (Taka) Payment Gateway

Set the UGLYPAY_API_KEY secret with wrangler secret put UGLYPAY_API_KEY - it's used both to call the gateway and to verify its webhook signature.

Withdrawals

Deducted from the requested amount; the user's balance is still debited the full requested amount, but the amount actually paid out is reduced by this fee.

Game Tuning ("gamer logic")

Nudges the provably-fair crash point using the current round's bets: a lot of players queued up biases toward a longer round; any single very large bet biases toward a fast crash.
